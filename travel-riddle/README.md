# Travel Riddle WordPress Theme

A custom, lightweight editorial theme built for Travel Riddle. It uses native WordPress templates, the Block Editor, responsive assets, accessible navigation, and no page-builder dependency.

## Install

1. Copy `travel-riddle` into `wp-content/themes/`.
2. Activate **Travel Riddle** in Appearance → Themes.
3. Create and assign a primary navigation and footer navigation.
4. Set a static page as the homepage under Settings → Reading.
5. Add posts with featured images to populate the homepage story grid.

## Content setup

- Create Home, Destinations, Stories, About, Contact, Privacy Policy, Disclaimer and Editorial Policy pages.
- Use Posts for travel stories.
- Configure the custom logo if it changes; the supplied logo is the fallback.
- Newsletter submission is visual-only until a provider or form handler is selected.

## Source materials

Brand assets and source documents remain in the provided `Documents And Resourses` folder. Copied web assets are stored inside `assets/` for theme portability.
